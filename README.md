# SEV7N FOLD — Website

A build-free, multi-page website for SEV7N FOLD. The public experience includes the company profile, product stories, one featured film on the homepage, and a dedicated cascading cinematic playground.

## Pages

- `index.html` — company homepage and one-film teaser
- `cinematic-playground.html` — full portrait film sequence
- `fold-motion.html`, `ava.html`, `uioutbox.html`, `foldbook.html`, `sev7n-signs.html` — product and concept stories

Serve or deploy the contents of this folder as static files, keeping the `assets` folder alongside the HTML pages. No build step is needed.

## Production status

The public pages are static and do not need a paid image, video, or hosting service. The cinematic page reads the same film list as the local editor and supports full TikTok post links or direct MP4 links.

Production is **not fully ready yet**. The public static pages are prepared, but the film list is currently saved only in browser storage. The existing SEV7N FOLD Supabase project is on the organization’s Free plan but paused. A restore attempt was blocked because the organization already has its two active Free projects (FoldBook and fold market). I did not pause either project because that would interrupt another product.

The editor is a local preview only: films and edits are saved in browser storage on the current device. It is available on `file://` previews and localhost; the floating editor control is hidden on hosted pages so visitors are not shown a non-functional admin tool. It is **not** a secure, shared CMS. An authenticated shared editor cannot be enabled until a Free project slot is available or the organization chooses another backend. Do not describe content management as production-ready until that step is complete.

No production domain or hosting target is configured here, so canonical URLs and a sitemap are intentionally not guessed.
